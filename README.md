# 3D Game for Android TV 🎮

A lightweight Java + libGDX 3D starter project designed for Android TV 11 and remote-control input.

## First prototype
- 3D ground and player
- Third-person follow camera
- D-pad / arrow-key movement
- Jump with Enter, Space, or the remote's center button
- APK built automatically by GitHub Actions

## Build the APK
1. Open the **Actions** tab.
2. Select **Build Android APK**.
3. Press **Run workflow** (or push a commit to `main`).
4. When the run finishes, open it and download the `3d-game-debug-apk` artifact.
5. Extract the ZIP and install `app-debug.apk` on your Android TV.

This is an early prototype; gameplay and collision will be expanded in later steps.
